# YouTube Compliance AI

This project establishes an automated Video Compliance QA Pipeline orchestrated by LangGraph, designed to audit content against regulatory standards using a Retrieval-Augmented Generation (RAG) architecture. The pipeline leverages cutting-edge technologies to transform unstructured video content into structured, actionable JSON compliance reports with deep full-stack observability.

## Key Components

### Multimodal Ingestion
- **Azure Video Indexer**: Extracts transcripts and OCR data from video content.

### Data Retrieval
- **Azure AI Search**: Retrieves relevant compliance rules using embeddings generated by Azure OpenAI.

### Reasoning Engine
- **Azure OpenAI (GPT-4o)**: Synthesizes data to deterministically detect compliance violations.

### Workflow Orchestration
- **LangGraph**: Manages and optimizes the LLM workflows.
- **LangSmith**: Provides granular tracing for workflow optimization.

### Observability and Monitoring
- **Azure Application Insights**: Enables production-grade telemetry, logging, and real-time performance monitoring.

## Features
- **Automated Compliance Checks**: Perform compliance checks automatically to save time and reduce errors.
- **Integration with Azure Functions**: Leverage serverless computing for efficient and scalable operations.
- **Modular Backend Architecture**: Easily extend and customize the pipeline to fit your specific needs.
- **Data Indexing and Management**: Includes tools for indexing and managing data efficiently.
- **Graph-based Workflow Management**: Define and manage workflows using a graph-based approach.

## Prerequisites

## Getting Started
1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```
2. **Navigate to the project directory**:
   ```bash
   cd ComplianceQAPipeline
   ```
3. **Set up the virtual environment**:
   ```bash
   python -m venv .venv
   .\.venv\Scripts\activate
   ```
4. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
5. **Run the application**:
   - For Azure Functions:
     ```bash
     func start
     ```
   - For the backend server:
     ```bash
     python backend/src/api/server.py
     ```

## Project Structure
- **azure_functions/**: Contains Azure Function app code and configuration.
- **backend/**: Includes the backend scripts, data, and services.
  - **scripts/**: Utility scripts for data indexing and other tasks.
  - **src/**: Source code for APIs, graph workflows, and services.
- **tests/**: Contains test cases for the project.
